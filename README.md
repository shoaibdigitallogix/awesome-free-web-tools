## Link Previews and Social Sharing

### Social Share Preview Checker

See exactly how a link will look when it is shared on **WhatsApp, Facebook, LinkedIn, X (Twitter), Discord, Slack, Telegram and iMessage**, before you share it. The checker reads the page the way link-preview crawlers do (raw HTML, no JavaScript), lists every Open Graph and Twitter Card tag, downloads the share image to confirm it really loads, and explains each problem in plain English with the fix. It also suggests a complete, copy-ready set of `og:` tags.

- **Answers:** Why is my WhatsApp link preview not showing an image? Why does my link show the wrong image or an old title? What size should an Open Graph image be?
- **Price:** Free, no sign-up.
- 🔗 **[Open the Share Preview Checker](https://www.cacheplex.com/share-preview-checker/)**

### Site-Wide Share Preview Scan

Checks the share preview of **every page in your sitemap** at once, instead of one URL at a time. It finds the problems a single check cannot show: pages with no share image, images that fail to load for crawlers, one default image on every page, and duplicate titles that make different pages look identical when shared. The homepage is checked first because it is the page shared most.

- **Answers:** How do I check Open Graph tags across my whole site? Which of my pages have no og:image?
- **Price:** First 5 pages free, no sign-up.
- 🔗 **[Open the Site-Wide Scan](https://www.cacheplex.com/share-preview-checker/site-scan/)**

### Link preview checkers for each app

Every app reads the same Open Graph tags but has its own rules for images, caching and layout. Each of these pages opens the checker on that app's preview and explains how to fix and refresh it there:

- **[Discord Embed Checker](https://www.cacheplex.com/share-preview-checker/discord/)**: why a Discord embed is missing, how to get the large image layout, and how `theme-color` sets the embed colour.
- **[Slack Link Preview Checker](https://www.cacheplex.com/share-preview-checker/slack/)**: test Slack link unfurls, and add "Reading time"-style fields with `twitter:label1` / `twitter:data1`.
- **[Telegram Link Preview Checker](https://www.cacheplex.com/share-preview-checker/telegram/)**: why Telegram shows an old preview and how to update it with @WebpageBot.
- **[iMessage Link Preview Checker](https://www.cacheplex.com/share-preview-checker/imessage/)**: how Apple Messages builds rich links on the sender's device, and why a link sometimes stays plain text.
- **[LinkedIn Post Preview Checker](https://www.cacheplex.com/share-preview-checker/linkedin/)**: why the LinkedIn image is missing or tiny, and how Post Inspector clears the cache.
- **[Facebook Link Preview Checker](https://www.cacheplex.com/share-preview-checker/facebook/)**: og:url mistakes, first-share images, and when to use the Sharing Debugger's Scrape Again.
- **[X (Twitter) Card Checker](https://www.cacheplex.com/share-preview-checker/x-twitter/)**: a Twitter Card Validator alternative now that X's validator no longer shows previews.

### PostPlex: Social Post Studio

Design social media posts from professionally built templates without design software. Edit the text directly on the canvas, choose the post size (square, portrait, story or landscape link image), and download a ready-to-upload PNG. Useful for quote posts, announcements and 1200 × 630 Open Graph share images.

- **Answers:** How do I make social media graphics if I'm not a designer? How do I make an Instagram quote post for free?
- **Price:** Free tier, with a paid upgrade for extra templates.
- 🔗 **[Open PostPlex](https://www.cacheplex.com/postplex/)**
